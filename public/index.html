組卷使用說明

  1. 選地區與範圍

    先在上方選宜蘭縣或都會區（可選「全部地區」混合出題），再選年級、學期與段考次別；每個地區按鈕與題型旁都會顯示實際可用題數。

  2. 決定題數與難度

    各題型可自行設定題數。難度可選混合或單一等級，混合比例可直接修改。自選單元會列出南一完整學期目錄，比例合計須為100%。單元模式會跨段考次別找題，年度與學校篩選仍有效。單元編號參照南一112學年度教材簡介本。

  3. 換題、調分

    按「換一題」只替換該題，保留其他題目與配分。選擇題統一同分，修改任一選擇題會同步整組。填充題由簡到難，平均配分後的餘分依困難、中等、簡單分配。其他題型可逐題修改；「重新配分」會依目標總分重算。

  4. 看原卷

    「歷屆考卷」可依地區、學校、年度篩選；勾選「只看可組卷的原卷」只列已轉成文字的考卷，可一鍵載入全卷或套用範圍組卷。

  5. 匯出與再修改

    下載 PDF 後，可用右上角「匯入 PDF / 紀錄」重新載入同一份蘭卷 PDF，再換指定題目。也可另存 JSON 組卷紀錄。一般外部 PDF 請由維護者先轉寫、核對後收錄，不會自動識別成題庫。

組卷紀錄儲存在這台瀏覽器。清除瀏覽資料會移除本機紀錄，請另存 PDF 或 JSON 備份。網站不要求登入或輸入學生個資。
