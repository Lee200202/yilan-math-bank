A SMALL GUIDE

從選題，到下一份練習。

  1. 選範圍

    選學年度、上下學期、年級、段考次別與學校；題數旁會顯示實際可用題量。

  2. 決定題數與難度

    三種題型可分別設定，難度比例合計 100%。題量不足不會複製題目湊數。

  3. 換題、調分

    生成後按某題的「換一題」，只替換同題型、同難度且未使用的題目。題頭分數可以直接修改；總分會即時更新，也可按「重新配分」回到目標總分。

  4. 匯出與再修改

    下載 PDF 後，可用右上角「匯入 PDF / 紀錄」重新載入同一份蘭卷 PDF，再換指定題目。也可另存 JSON 組卷紀錄。一般外部 PDF 請由維護者先拆題收錄，不會自動識別成題庫。

組卷紀錄儲存在這台瀏覽器。清除瀏覽資料會移除本機紀錄，請另存 PDF 或 JSON 備份。網站不要求登入或輸入學生個資。
