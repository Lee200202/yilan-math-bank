# 舊版 Word 考卷辨識工作

此目錄保存難以直接擷取的來源辨識紀錄。這些紀錄不是已完成的考卷，也不構成發布許可。轉錄稿只有在題意與必要圖形可還原時才應投入題庫；無法確認的內容應標明問題，不得自行推測。

`extract_reference.py` 是本次診斷腳本備份，執行前需依其說明取得外部 GPL-2.0-or-later 的 MathType 解析器及 olefile；外部解析器和 LibreOffice 不隨本儲存庫附帶。`drafts/` 明確為尚未發行稿，不屬網站正式題庫。
