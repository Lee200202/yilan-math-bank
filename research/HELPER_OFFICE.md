# Helper brief for Word/ODT papers (use together with research/HELPER_PROMPT.md; this file overrides the PDF-specific steps)

The paper exists only as .docx / .odt. It was already unpacked for you (no Word needed):

- `office` field of each target = `research/targets/office/<paperId>/text.md` — the paper's text in reading order, exact (copy numbers/wording from it; do NOT retype from memory).
  - Formulas are already LaTeX in `$...$` (check them; `\overline{AB}` = segment, `\overset{\to}{BE}` = ray, etc. Use the standard forms in TRANSCRIBE_GUIDE.md).
  - `[IMG img/NN.png]` = a figure/picture at that spot; the file is in the same folder (`research/targets/office/<paperId>/img/NN.png`). VIEW each with the Read tool and redraw it as vector SVG per the guide. `NN.wmf/.emf/.jpg` are originals; use the `.png` rendering. Small formula pictures are also IMG: they are the formula itself, read it.
  - `[TEXTBOX] ... [/TEXTBOX]` = text inside a text box. `[TABLE] ... [/TABLE]` = table (cells separated by ` | `, cell paragraphs by ` / `).
  - `(auto-numbered)` = the question number was generated by Word and is not in the text; number sequentially in order within each section and cross-check with the answer sheet if any.
  - `____` = a blank. `[DRAWING-SHAPE ...]` = a vector figure the extractor could not draw (rare): reconstruct from the surrounding text and mention it in your report.
  - `[OBJECT Object N]` before an IMG is the picture's embedded object (ignore the label).
- **Equation pictures can render garbled** (MathType: overlapping glyphs or blank PNG). The original `.wmf` is next to the PNG in `img/`. Read it with `python -X utf8 research/metro/wmf_text.py <file.wmf>` (prints the characters with x/y positions; Symbol-font bytes: 0xB1 ±, 0xB4 ×, 0xB8 ÷, 0xD6 √), and confirm against the answer key. If still unreadable, mark the question `usable:false` with a sourceIssue; never guess.
- If text.md and an image disagree, the image is what the teacher saw. Page header (school/semester/exam) is on a `[HEADER]` line when present.
- Legacy `.doc` papers were first converted to `.docx` by the installed Word (`scripts/word_convert_batch.py`); `text.md` is extracted from that .docx. Word turns old Equation-Editor formulas into real equations (you see `$...$`), and keeps other OLE objects as WMF/EMF pictures (`img/NN.png`, original `.wmf` beside it). `sourceSha256` is still the SHA of the ORIGINAL .doc (target `source` field).
- There is NO PDF and no page render. Skip the render_pages step. Header/slot check: use the title line in text.md. If there is only an answer key / no questions, put it in skipped.json.
- Source type for the JSON: sourceSha256 = sha256 of the original file named in the target's `source` field (must equal papers.json for that paperId). Set `page` of every question to 1.
- Everything else (schema, SVG rules, difficulty, units, check_transcript.py, own scratch folder, no git/build) is as in HELPER_PROMPT.md. Keep the same quality bar: reread every question against text.md and the images at the end.
- Since the text is exact, you may spend your effort on figures and on difficulty/unit judgement. Report anything the extraction mangled.
