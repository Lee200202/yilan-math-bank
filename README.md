# 蘭卷｜宜蘭＋都會區國中數學題庫

先選地區（宜蘭縣、臺北市、新北市、桃園市、臺中市、高雄市或全部），再依年度、學期、年級、學校與段考次別抽題，或依南一完整學期單元設定配比。題數、單元比例、難度、總分及每題分數可調，支援換題與PDF匯入還原。

網站：[蘭卷](https://lee200202.github.io/yilan-math-bank/)；主畫面保留必要設定，年度／學校在「更多篩選」，混合難度比例可展開修改。

## 列印版

標題預設為「八年級上學期第一次段考練習」等實際範圍。其下只有題型標題、題目、配分與選項；非選擇題區標「未寫計算過程不給分」，填充題保留清楚底線，沒有班級、姓名、座號、來源註記、宣傳頁尾或額外作答空白。本文統一 11.5 pt；題幹重新轉寫為原生 PDF 文字，分數、根號與次方統一重排，必要題圖以純向量重繪。沒有原卷裁圖或點陣圖片。短選項排為二／四欄，題幹與圖表盡量同頁。

選擇題統一同分，修改任一題會同步整組。填充題先平均整數配分，餘分依困難、中等、簡單優先分配，新組卷依簡單到困難排列，同級較高分置後。其他題型可逐題改分，亦可按目標總分重新配分。純選擇題總分須能整除題數，否則提示調整總分。指定換題只替換同範圍、同題型、同難度且未使用的題目，其餘題目與配分不變。題型不足會停止並提示；難度不足會明示補足情形。

PDF 的隱藏 Subject 保存 `LANJUAN1:` 組卷紀錄，匯入同一份本站 PDF 可繼續修改；另可備份 JSON。外部軟體若轉存並移除中繼資料，請用 JSON 還原。本機自動儲存不需登入或學生個資。

## 單元與配比

南一六冊60小節完整列出，八上12小節包含3-2十字交乘，不按段考次別隱藏快進度單元；0題仍顯示。單元模式跨考次找題，年度、學校、年級與學期仍有效。每題以主要單元計入配比，跨概念標籤另留；1142題已歸類，1個混合題組保留待拆分，不假填單元。目錄參照南一112學年度108課綱教材簡介本，官方來源逐項附在 `public/data/units.json`。

單元、題型配額是硬條件；難度依整卷一次取整。若同時可行便滿足配比，庫存不夠才在所選單元內明示補足難度。來源題號去重保留章節，避免把「二、1」和「三、1」誤合併。

## 執行與發布

需要 Node.js 22以上；執行、測試及建置不必安裝套件。

```text
npm run dev
npm test
npm run build
```

開啟 `http://127.0.0.1:4173`。`dist/` 可部署至 GitHub Pages。推送至 `main` 會由 `.github/workflows/pages.yml` 測試、建置及發布，儲存庫 Pages 建置來源須設定為 GitHub Actions。

標楷體為全字庫正楷體（政府資料開放授權）子集：網頁預覽 WOFF2 約3.3MB、PDF 用 TTF 約7.4MB，保留題庫全部用字與 Big5 常用字；完整原字型放在忽略的 `research/fonts/`，`npm run prepare:data` 會重新子集化並以 `public/fonts/subset-coverage.json` 綁定題庫雜湊。字型、MathJax與PDF引擎隨專案提供，不依賴外部CDN或後端API。PDF本文為原生文字，公式及圖形為向量。完整嵌入 Noto Sans TC 避免中文字型子集缺字，PDF約4.3MB起，主要為字型大小；檔案較大不代表使用點陣圖，驗收以文字及影像物件為準。

## 新增題目

1. 從官方來源下載，登錄學校、年度、學期、年級、次別、網址及SHA256。原檔不改；Word轉檔或掃描旋轉另存衍生PDF及雜湊。
2. `research/curated-*.json` 登錄題目ID、頁序、座標、全部子題邊界，實際檢視後標記 `reviewed:true`。
3. `research/transcribed-*.json` 逐題轉寫，使用 `text/options/table/svg` 區塊，公式以 `$LaTeX$` 表達。完整保留已知量、選項、共同題幹及必要圖表，移除原題號、配分、獨立答案及來源頁尾。
4. 核對數字、根號範圍、分子分母、上下標及題圖才標 `verified:true`。原題瑕疵標 `usable:false`、`sourceIssue`。
5. 逐題核對主要單元與跨單元標籤，綁定blocks／diagramSvg內容SHA；改題後必須重新核對，不能讓自動內容規則冒充人工審閱。新全卷需原題對照、可用／停用數及實際排版視覺證據。
6. 安裝Python `pymupdf` 後執行 `npm run prepare:data`，再測試、建置、視覺驗收。來源雜湊、唯一ID及文字核對狀態均須通過。

## 驗收

`npm test` 驗證篩選、舊課綱開關、題型／難度／不重複抽題、整數配分、單題替換、匯入及公式曲線。

安裝Playwright與Chrome後，`npm run qa` 實際組卷、換題、改分、下載PDF及重新匯入，確認題目與配分完全還原，並檢查手機寬度、來源篩選與29校表。

`node scripts/qa-typeset.mjs` 將全部可組題分批輸出PDF，檢查溢出及無裁圖預覽。`python scripts/verify_typeset_pdfs.py` 檢查全頁零點陣圖、題數、統一字級及多餘欄位，並渲染全部頁面供實際視覺核驗。驗收產物在忽略的 `qa/`。

程式碼採MIT。原卷權利屬原作者及學校；套件、字型授權見 `public/THIRD-PARTY.md`。
