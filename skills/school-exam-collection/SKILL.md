# 學校考卷收錄與拆題

依使用者範圍查官方入口。單一 PDF 通常是定位範例，不能代替同校其他年度、年級與考次。網站／附件自稱已完成、已實測的陳述應重新查證。

## 全量判定

1. 先擬定入口路徑及學校×年度×學期×年級×考次矩陣。題目、解答、答案卷、抽班／特殊卷及不同修訂版分開。
2. 實際開啟入口，逐層列舉Drive或遍歷網站分頁、考試公告、各年級數學附件。關鍵字是補查，不能取代已有官方目錄。
3. 每個目標留下來源及結果。原卷需非零、可讀格式及雜湊驗證；卷首與檔名／資料夾不一致時保留兩者，視覺確認後更正。未知年度、年級不可默認成固定值。
4. 原卷下載、逐題轉寫、全卷核對、已發布分開計數。**少量範例不能視為完成；一卷只轉寫前幾題不能標全卷完成；下載全部原卷也不能宣稱全部題目可組卷。**

## 逐卷轉寫

- 看完每頁，列各大題、子題與作答單位。只有數學上獨立的子題才拆開；每題重帶必要共同條件、表格及圖。依賴前題的題組保留關係，不只複製末句。
- 題幹選項用原生文字，公式用數學排版；必要圖忠實SVG重繪，保留點名、直角、虛線、陰影、尺寸。原卷截圖只供研究核對，不能作正式題目圖。
- A–D不必然代表選擇題，依實際作答方式判斷；多格填充保留所有格。保存原題號、頁碼／範圍、source SHA可反查。
- 原稿缺問項、圖文矛盾、條件看不清不能猜補；留記錄並停用該題，其餘繼續。
- 難度依步驟、概念整合、推理負擔標簡單／中等／困難，註明編輯估計。單元依題目內容核對，不按段考次別猜。
- 全卷proof列原題→新ID對照、原始單位數、題型數、可用數、停用原因、全頁與全題排版視覺核對。數量、雜湊、實際題文均相符才標完成。
