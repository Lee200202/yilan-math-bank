# 公開 Drive 全量盤點

交付可追溯的完整清單與可讀原檔，而非幾個示範連結。

- 先確定根目錄、範圍與應列維度。實際開啟使用者指定入口，確認畫面路徑，再用可重現的遞迴盤點減少重複操作。
- 保留原 folder/file ID、檔名、父層 ID、完整路徑、來源 URL、時間。保留提供的 resourcekey，不假定需要變更權限。
- 每個範圍內子資料夾都要有盤點結果；處理分頁／虛擬清單，不把第一屏當全部。空資料夾、未列檔案、讀取錯誤、需登入分開記錄。
- 下載後檢查非零位元組、實際格式、可讀頁數與 SHA256。HTTP 200 不代表成功：HTML、登入頁與零位元組不能算 PDF。既有原檔雜湊符合可重用，保留本次重查目錄的證據。
- 用 ID 去重目錄，用內容雜湊找同檔別名；不能只因檔名相似而合併。保留重試結果，不把一次連線失敗說成「沒有資料」。
- 全量完成條件：範圍內資料夾皆已列舉；所有目標檔案已驗證下載，或逐項說明無法取得原因；清單與本機原檔數對得上。**少量範例、只開一個檔案或只列出網址，不代表全量完成。**
